# CombatRaven

CombatRaven is a starter project scaffold for a Python-based application.

## Project structure

- src/ - application source code
- assets/ - static assets
- docs/ - project documentation
- tests/ - automated tests

## Getting started

1. Create and activate a virtual environment.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start implementing your application in the src directory.

# Combat Raven

Combat Raven es una aplicación de escritorio para gestionar combates de juegos de rol.

Su objetivo es ofrecer una interfaz extremadamente rápida para llevar:

- iniciativa
- HP
- condiciones
- duración de efectos
- acciones legendarias
- acciones de guarida
- registro del combate

Pensada para campañas largas y Directores de Juego que necesitan velocidad durante la sesión.
